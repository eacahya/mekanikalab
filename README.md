# Mekanika Lab

Aplikasi pendamping buku **Mekanika: Dari Newton hingga Lagrange** (Dr. Ea Cahya Septia Mahen, S.Pd., M.Si.).

Berisi 29 simulasi interaktif untuk Bab 1–14. Setiap simulasi dapat dibuka langsung dengan kode SIM, misalnya:

- `https://eacahya.github.io/mekanikalab/#SIM-1.1`
- `https://eacahya.github.io/mekanikalab/#SIM-13.2`

Kode QR di dalam buku mengarah ke alamat-alamat tersebut. Aplikasi berupa satu berkas `index.html` tanpa dependensi eksternal, sehingga juga dapat dibuka secara luring.
